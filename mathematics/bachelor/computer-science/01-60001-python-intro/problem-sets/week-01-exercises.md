# 参考答案与解析（做完再看）

## 1. a 声明性（"是什么"）；b 程序性（"怎么做"的步骤）；c 声明性（事实陈述）；d 程序性（算法）。
新例子自拟，检验标准：能"陈述"的是声明性，能"执行"的是程序性。

## 2. 解释器逐条读取并执行"另一个程序"（你的 Python 代码），而指令可以被当作数据存进内存、随时替换——这正是冯·诺依曼存储程序架构的定义。

## 3.
a) `14`（先乘后加）
b) `20`（括号优先）
c) `512`——幂右结合：`3**2=9` 先算，再 `2**9=512`（易错：不是 64）
d) `3` 和 `1`
e) `-4`！`//` 是向下取整，-3.25 往下取是 -4（配套：`-13 % 4 = 3`）。**负数整除向下取整**是 Python 的规定，与 C 不同。

## 4. 输出 `15 10`。`b = a` 绑定的是**当时的对象 10**；之后 `a = a + 5` 让 a 重绑定到新对象 15，与 b 无关——绑定一旦复制，各自独立。

## 5. **版本一对**。Python 先把右边 `(y, x)` 打包求值（得到 `(2, 1)`）再解包赋值，天然原子操作。
版本二：`y = x` 之后 y 已变成 1，原来的 2 被覆盖丢失，`x = y` 只是把 1 再赋给 x——两行后都是 1。

## 7.

total = 7385

## 8.

| 轮次 | g | g² |
|---|---|---|
| 0 | 3 | 9 |
| 1 | (3 + 25/3)/2 ≈ 5.6667 | 32.11 |
| 2 | (5.6667 + 25/5.6667)/2 ≈ 5.0368 | 25.369 |
| 3 | ≈ 5.000134 | 25.0013 |

3 轮后已收敛到 25 附近——这就是"程序性知识"的力量：不背 √25=5，用算法逼近它。
