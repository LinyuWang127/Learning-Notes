# 6.0001 · Introduction to Computer Science and Programming in Python （Python 编程入门）

> **课程主页**：[Fall 2016 · Dr. Ana Bell & Prof. Eric Grimson](https://ocw.mit.edu/courses/6-0001-introduction-to-computer-science-and-programming-in-python-fall-2016/)
> **预估投入**：约 90 小时
> **先修**：无（零基础入门）

## 课程定位（为什么学它）

一切从这里开始。变量与控制流、函数、复杂数据类型到面向对象——整个作品集 `code/` 目录的主语言就是 Python，先把工具拿稳。每讲都有随堂练习，配套习题集完整。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融工程的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 古典密码（凯撒 / 维吉尼亚）的加密实现与频率分析破译
- 房贷摊销表与二分法求根：数值直觉的第一个编程项目
- Python 内存模型与性能剖析：profile 一个科学计算脚本
