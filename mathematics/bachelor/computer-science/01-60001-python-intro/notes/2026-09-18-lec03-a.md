## 今天的主线

字符串玩出花 + 把"先猜后验"升级成完整算法：**穷举（exhaustive enumeration）**。

## 1. 切片与不可变性

```python
s = 'abcdefgh'
print(s[2:5])     # 'cde' —— 下标 2 到 4，含头不含尾
print(s[:3])      # 'abc' 省略起点 = 从 0
print(s[3:])      # 'defgh' 省略终点 = 到结尾
print(s[::-1])    # 'hgfedcb' 步长 -1 = 反转，面试常用
```

⚠ 字符串**不可变**：`s[0] = 'X'` 直接 TypeError。所谓"改字符串"其实是造一个新串。

```python
s = 'hello'
s = 'H' + s[1:]   # 合法：拼接产生新串，再绑回 s（L1 绑定知识复用）
```

## 2. 穷举 —— 最笨但最诚实的算法

问题：27 的立方根是多少？暴力解法：**把 0 到 27 每个数都试一遍**，谁的三次方等于 27 谁就是答案。

```python
x = 27
ans = 0
while ans**3 < x:          # 还没超过，就继续试下一个
    ans = ans + 1
if ans**3 != x:
    print(str(x) + ' 不是完全立方数')
else:
    print('立方根是 ' + str(ans))   # 3
```

三个要点：
1. 循环条件用 `<` 而不是 `!=`——`<` 保证一定能退出，`!=` 在没有答案时会**跳过去**然后死循环找不到。
2. 出循环后**必须再验证一次**（`ans**3 != x`）——循环退出有两种可能：找到了，或试完了。这是穷举的灵魂。
3. 穷举 = 搜索空间有限 + 验证便宜。LC 第 1 题两数之和的暴力解就是这个，之后学的哈希表是把"验证"加速到 O(1)。

## 3. 与刷题联动（今天的 Day 5 题：11. 盛最多水）

- 穷举版：所有 `i<j` 组合都算面积 → O(n²)
- 聪明版：左右对撞双指针，每次移动短板 → O(n)
- 两版答案相同，差别只在**不试那些注定更差的情况**。这个"剪掉注定更差"的思想，就是从穷举到贪心/二分的桥——L3 后半要讲的**二分法**是它最优雅的形态。
