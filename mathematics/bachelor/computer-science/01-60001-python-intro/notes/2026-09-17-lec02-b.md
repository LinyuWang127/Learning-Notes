## 昨天会看路了，今天让程序会打转

分支解决"选哪条路"，循环解决"重复一万次"。量化里最朴素的回测就是：`for` 每一天的数据，做一遍判断。

## 1. while 循环 —— 三要素缺一死

```python
n = 0            # ① 初始化
while n < 5:     # ② 条件
    print(n)
    n = n + 1    # ③ 更新 —— 忘了这行 = 死循环
```

三要素：初始化、条件、更新。任何一环没接上，要么一次不跑，要么永远跑。

## 2. break —— 够了就走

```python
while True:               # 表面死循环
    line = input('> ')
    if line == 'q':
        break             # 但内部给了出口
    print(line)
```

`while True + break` 是"循环次数未知、看情况停"的标准姿势。

## 3. for + range —— 次数已知就用它

```python
for i in range(5):        # 0 1 2 3 4 —— 不含 5！
    print(i)

for i in range(2, 10, 2): # 2 4 6 8 —— start, stop, step
    print(i)
```

⚠ `range(1, 11)` 才是 1 到 10。**stop 永远取不到**，这个坑在刷题里每周都会踩一次。

## 4. 字符串遍历

```python
s = 'abc'
for c in s:        # 'a' 'b' 'c' 逐字符
    print(c)
print(len(s))      # 3
print(s[0])        # 'a' 索引从 0 开始
```

## 5. 累加器模式 —— 本周最重要的套路

```python
total = 0
for i in range(1, 101):
    total = total + i
print(total)       # 5050
```

「循环体外建变量 → 循环体内累加 → 循环体外用结果」。LeetCode 里一半的题都是这个骨架换皮。

## 自查 3 题（答案在折行处）

1. `for i in range(3): print(i)` 输出？
   → 0 1 2（range(3) 不含 3）。
2. while 循环里忘了 `n = n + 1` 会怎样？
   → 死循环，条件永远为真。
3. 用累加器算 1×2×3×…×10（提示：total 初值改 1，运算改乘）？
   → `total = 1`，`for i in range(1, 11): total *= i`，结果 3628800。
