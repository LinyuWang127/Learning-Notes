## 2. 声明性知识 vs 程序性知识（本讲最重要的分界）

| 类型 | 是什么 | 平方根的例子 |
|---|---|---|
| 声明性 declarative | **是什么**的陈述，断言事实 | y² = x，x = 25 的平方根是使该式成立的数 |
| 程序性 imperative | **怎么一步步做**的配方/过程 | 牛顿法：猜 g → 检查 g² 是否够接近 x → 否则 g = (g + x/g)/2 → 重复 |

- 陈述一个事实 ≠ 会算。计算机科学关心的是**程序性知识**——把「怎么算」写成有限步骤。
- 记忆锚点：**菜谱**。声明性知识是"这道菜好吃"，程序性知识是菜谱本身。

## 3. 算法（algorithm）三特征

1. 指令序列**有限**（finite）
2. 每条指令**确定**（no ambiguity——同一输入永远走同一路径）
3. 执行完**会停**（terminates），并给出结果

牛顿法为什么是算法：每一步完全确定、循环有限次后 ε 收敛、输出近似解。

## 4. 机器模型的演进（理解"解释器"从哪来）

```
fixed-program computer  →  stored-program computer  →  interpreter
固定程序机器                存储程序计算机                解释器
（只会一套算，如计算器）     （指令也是数据，存进内存       （逐条读取并执行
                             可换程序，冯·诺依曼架构）      存储的程序本身）
```

- **Python 解释器 = 一台存储程序机器上的程序**，它读的是"另一个程序"（你的代码）。这一层关系讲清楚了"写代码"到底在干什么。

## 5. Python 对象：万物皆对象

每个对象三要素：**identity（身份）、type（类型）、value（值）**。

- **标量对象**（不可再分）：`int`、`float`、`bool`、`NoneType`
- **非标量对象**：有内部结构，可拆（如 `str` 由字符组成）

## 6. 表达式与操作符

`<对象> <操作符> <对象>` 组成表达式 → 解释器求值 → 得到对象。

```python
>>> 3 + 4 * 5      # 乘法优先
23
>>> (3 + 4) * 5    # 括号最优先
35
>>> 2 ** 3         # 幂
8
>>> 7 / 2          # 真除法，永远得 float
3.5
>>> 7 // 2         # 整除（向下取整）
3
>>> 7 % 2          # 取余
1
```
