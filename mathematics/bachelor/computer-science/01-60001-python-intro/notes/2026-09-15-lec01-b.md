## 1. 变量与绑定（本讲最后一个大概念）

赋值语句 `name = value` 的语义：**把名字绑定到对象上**，不是"把值放进盒子"。

```python
pi = 3.14159      # 名字 pi 绑定到 float 对象 3.14159
radius = 11.2     # 名字 radius 绑定到 float 对象 11.2
area = pi * radius ** 2   # 求值右边 → 把结果绑定给 area
```

三条规则：

1. 名字必须**先绑定再使用**，否则 `NameError`。
2. 重新赋值 = **重绑定**（旧绑定被覆盖，旧对象可能被回收）。
3. `x = y` 复制的是**绑定**，不是对象本身——两个名字指向同一个对象，之后各自重绑定互不影响。

## 2. 今天的头号陷阱：绑定 vs 同步

```python
x = 5
y = x      # x、y 都指向 5
x = 7      # 只是 x 改指 7，y 不动
print(x, y)   # 7 5  —— 不是 7 7！
```

面试常考的追问：**为什么 `x = x + 1` 合法？** 因为 `=` 不是数学等号，是先求值右边、再绑定左边。

## 3. 复合赋值与字符串操作

```python
count += 1     # 等价 count = count + 1
name = "Lynn"
name * 3       # 'LynnLynnLynn'（str 支持 * 重复）
"Lynn" + "127" # 拼接
"Lynn" + 127   # TypeError —— str 与 int 不能混用 +
```

类型转换三件套：`int("127")`、`float("3.5")`、`str(127)`——显式转换是消灭 TypeError 的第一工具。

- `=` 是**绑定**：右边求值 → 左边命名，方向永远从右到左。
