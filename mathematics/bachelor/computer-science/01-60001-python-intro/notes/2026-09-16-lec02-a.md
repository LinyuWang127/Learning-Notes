## 1. 比较与 bool 类型

比较运算符：`==` 等于、`!=` 不等于、`>` `<` `>=` `<=`。
结果只有两个值，类型叫 **bool**：`True` / `False`（⚠ 首字母必须大写，`true` 是错的）。

```python
print(3 == 3.0)    # True  —— 值比较，不管类型
print('a' < 'b')   # True  —— 字符串按字典序比
print(0.1 + 0.2 == 0.3)  # False！浮点误差，经典坑
```

## 2. 逻辑运算符 and / or / not

- `a and b`：两个都真才真（短路：a 假就不看 b）
- `a or b`：一个真就真（短路：a 真就不看 b）
- `not a`：取反

```python
grade = 85
print(grade >= 80 and grade < 90)   # True —— 区间判断的标配写法
```

## 3. if / elif / else —— 缩进即语法

```python
x = int(input('Enter a number: '))
if x % 2 == 0:
    print('Even')
else:
    print('Odd')
print('Done with conditional')
```

三个要点：
1. **冒号 + 缩进**定义代码块，Python 不用花括号。缩进错误不是风格问题，是语法错误。
2. `elif` 可以有任意多个，从上往下**命中即停**——后面的分支不再看。
3. `if x % 2 == 0` 里 `==` 别写成 `=`：`=` 是绑定，`==` 才是比较（L1 的知识在这里第一次变成 bug 来源）。

## 4. guess-and-check 的思想雏形

L2 前半埋了一个重要思想：**先猜，再验证**。

```python
x = 25
ans = 0
if ans**3 < x:   # 检验 ans 是不是答案
    ...
```

验证很便宜，搜索很贵——这是 L3 二分法和整个算法世界的种子。刷题里 Day 1 的两数之和（先存起来再查）本质也是"验证快，就可以暴力枚举"。
