# 15.071 · The Analytics Edge （数据分析 · R 语言）

> **课程主页**：[Spring 2017 · Prof. Dimitris Bertsimas](https://ocw.mit.edu/courses/15-071-the-analytics-edge-spring-2017/)
> **预估投入**：约 120 小时
> **先修**：基础统计（可与 18.05 同步）

> 注：OCW 官网层级标注为 Graduate，实际内容为数据科学入门课；因课程定位与语言训练放在本科层。

## 课程定位（为什么学它）

R 语言 + 线性回归 / 逻辑回归 / 决策树 / 文本分析 / 优化，案例全用真实数据（Moneyball、IBM Watson、Framingham 心脏研究、Netflix）。金融数据分析的行业语言之一是 R，这门课一次拿到位；9 次作业 + 期末小组项目，产出非常适合放进作品集。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融工程的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 用 R 复现 Framingham 心脏病预测模型（逻辑回归）
- Moneyball：棒球数据分析的方法论复述与批判
- 文本分析：从 Bag of Words 到情感预测的 R 实践
