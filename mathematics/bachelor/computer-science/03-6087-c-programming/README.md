# 6.087 · Practical Programming in C （C 语言实战）

> **课程主页**：[January IAP 2010 · Dr. Daniel Weller & Sharat Chikkerur](https://ocw.mit.edu/courses/6-087-practical-programming-in-c-january-iap-2010/)
> **预估投入**：约 80 小时
> **先修**：任一门编程入门（建议 6.0001 之后）

## 课程定位（为什么学它）

指针、内存模型、位运算、编译链接——OpenSSL、libsodium、GMP 等密码库全是 C 写的。学完它才能读懂真实的密码实现、理解缓冲区溢出与侧信道攻击为什么会发生。密码学方向的 C 是刚需，不是选修。

## 建议论文方向

- 用 C 实现大整数运算库（加 / 乘 / 模幂）并与 Python 性能对比
- 缓冲区溢出攻击原理与内存安全防御综述
- 位运算技巧及其在密码实现中的应用
