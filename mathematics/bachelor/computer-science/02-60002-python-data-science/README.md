# 6.0002 · Introduction to Computational Thinking and Data Science （计算思维与数据科学）

> **课程主页**：[Fall 2016 · Dr. Ana Bell / Prof. John Guttag](https://ocw.mit.edu/courses/6-0002-introduction-to-computational-thinking-and-data-science-fall-2016/)
> **预估投入**：约 90 小时
> **先修**：6.0001

## 课程定位（为什么学它）

随机模拟（蒙特卡洛）、优化、图、聚类——金融工程两大数学支柱（随机 + 优化）的编程直觉版。Guttag 讲的统计思维与假设检验直接对接后面的 18.05 / 18.600。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融工程的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 蒙特卡洛模拟：从估计 π 到期权价格（前奏版）
- 背包问题：动态规划与贪心策略的对比实验
- 随机游走与统计置信：Guttag 章节的复述与扩展
