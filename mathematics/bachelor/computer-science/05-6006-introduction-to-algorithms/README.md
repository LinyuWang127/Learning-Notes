# 6.006 · Introduction to Algorithms （算法导论）

> **课程主页**：[Spring 2020 · Prof. Erik Demaine & Prof. Srini Devadas](https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/)
> **预估投入**：约 150 小时
> **先修**：6.0001；建议与 6.1200J 同步

## 课程定位（为什么学它）

排序、哈希、图、动态规划、复杂度分析——一切程序效率的地基。密码协议实现的效率度量（大数运算、素性检测）与后续 6.046J 的全部内容都建立在这门课上。视频、讲义、习题全套。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融工程的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 大整数乘法算法对比：Karatsuba vs. 朴素竖式
- 图算法在金融网络清算路径中的应用
- 哈希表与冲突解决：性能实验与理论分析
