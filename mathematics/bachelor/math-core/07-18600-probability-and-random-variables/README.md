# 18.600 · Probability and Random Variables 概率与随机变量

> **课程主页**：[Fall 2019 · Prof. Scott Sheffield](https://ocw.mit.edu/courses/18-600-probability-and-random-variables-fall-2019/)
> **预估投入**：约 150 小时
> **先修**：18.02

## 课程定位（为什么学它）

18.05 的理论升级版：分布族、条件期望、大数定律、中心极限定理、鞅入门。Sheffield 讲义包含熵与风险中性概率两讲——直通信息论密码学和衍生品定价。测度论之前最重要的概率课。
