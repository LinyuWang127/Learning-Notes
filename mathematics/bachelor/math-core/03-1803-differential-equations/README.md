# 18.03 · Differential Equations 常微分方程

> **课程主页**：[Spring 2010 · Prof. Haynes Miller / Prof. Arthur Mattuck](https://ocw.mit.edu/courses/18-03-differential-equations-spring-2010/)
> **预估投入**：约 150 小时
> **先修**：18.01（18.02 可同修）

> **替代版**：自学向替代版（含分步解题视频）：18.03SC Fall 2011 — https://ocw.mit.edu/courses/18-03sc-differential-equations-fall-2011/

## 课程定位（为什么学它）

MIT 140 余门课的前置。Black-Scholes 偏微分方程、随机过程的确定性骨架、动力系统全部从这里出发。Mattuck 的 Notes and Exercises 是镇课之宝。
