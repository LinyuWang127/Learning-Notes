# 18.01SC · Single Variable Calculus 单变量微积分

> **课程主页**：[Fall 2010 (OCW Scholar 自学版) · Prof. David Jerison](https://ocw.mit.edu/courses/18-01sc-single-variable-calculus-fall-2010/)
> **预估投入**：约 150 小时
> **先修**：高中数学

## 课程定位（为什么学它）

微积分起点。OCW Scholar 版专为自学设计：完整讲义视频 + 习题 + 试卷全带解答，不需要任何外部教材。泰勒展开与级数收敛是后续数值分析和误差分析的根基。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业（如适用）
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融科技的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- Taylor 近似的误差界与数值算法中的舍入控制
- 极限交换条件在级数求和中的应用（以 Fourier 级数预告）
