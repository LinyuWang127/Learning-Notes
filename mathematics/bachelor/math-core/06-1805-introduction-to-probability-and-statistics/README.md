# 18.05 · Introduction to Probability and Statistics 概率统计入门

> **课程主页**：[Spring 2022 · Dr. Jeremy Orloff / Dr. Jennifer French Kamrin](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/)
> **预估投入**：约 120 小时
> **先修**：18.02

## 课程定位（为什么学它）

同时教贝叶斯和频率派两条推断主线，配 R 语言实战。对金融科技方向：这是统计推断的世界观课；对密码学：概率论证（生日攻击、碰撞概率）的基础。
