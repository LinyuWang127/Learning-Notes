# 18.02 · Multivariable Calculus 多元微积分

> **课程主页**：[Fall 2007 · Prof. Denis Auroux](https://ocw.mit.edu/courses/18-02-multivariable-calculus-fall-2007/)
> **预估投入**：约 150 小时
> **先修**：18.01 单变量微积分

## 课程定位（为什么学它）

向量、矩阵运算、偏导、多重积分。金融科技中的多变量优化（组合优化、梯度法）和机器学习损失面分析全部依赖本课。Auroux 版有完整 35 讲视频。
