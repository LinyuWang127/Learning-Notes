# 18.06 · Linear Algebra 线性代数

> **课程主页**：[Spring 2010 · Prof. Gilbert Strang](https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)
> **预估投入**：约 150 小时
> **先修**：18.02 多元微积分

> **替代版**：自学向替代版：18.06SC Fall 2011 — https://ocw.mit.edu/courses/18-06sc-linear-algebra-fall-2011/

## 课程定位（为什么学它）

Strang 的 18.06 是全球公认最好的线代课。四个基本子空间、SVD、正定性——格密码（lattice-based cryptography, LLL 算法）的主战场，也是量化金融矩阵计算的通用语言。
