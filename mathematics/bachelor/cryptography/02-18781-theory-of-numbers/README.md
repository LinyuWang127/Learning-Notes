# 18.781 · Theory of Numbers 数论

> **课程主页**：[Spring 2012 · Prof. Abhinav Kumar](https://ocw.mit.edu/courses/18-781-theory-of-numbers-spring-2012/)
> **预估投入**：约 120 小时
> **先修**：无正式先修（需证明熟练度）

## 课程定位（为什么学它）

初等数论完整版：同余、中国剩余定理、原根、二次互反律、连分数。日历里有整整一讲讲 RSA。这是密码学博士面试的高频考点课。
