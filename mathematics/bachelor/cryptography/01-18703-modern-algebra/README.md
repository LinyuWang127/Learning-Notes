# 18.703 · Modern Algebra 近世代数（抽象代数）

> **课程主页**：[Spring 2013 · Prof. James McKernan](https://ocw.mit.edu/courses/18-703-modern-algebra-spring-2013/)
> **预估投入**：约 120 小时
> **先修**：18.02（证明经验有帮助）

## 课程定位（为什么学它）

群、环、域一学期完整版：Lagrange 定理、Sylow 定理、唯一分解、有限域分类。AES 的 Galois 域 F_2^8、Diffie-Hellman 的循环群、RSA 的环 Z/nZ——现代密码学的代数骨架全在这门课里。
