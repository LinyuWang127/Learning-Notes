# 18.701 · Algebra I 抽象代数 I（Artin）

> **课程主页**：[Fall 2010 · Prof. Michael Artin](https://ocw.mit.edu/courses/18-701-algebra-i-fall-2010/)
> **预估投入**：约 150 小时
> **先修**：18.703（或同步进行）；教材为 Artin 本人所著《Algebra》

## 课程定位（为什么学它）

Artin 的 Algebra I 是 MIT 数学专业的荣誉线抽象代数（比 18.703 更理论化、证明更完整）：
群论、群作用、Sylow 定理、线性群、环与域初步。想读懂椭圆曲线与格密码的原始论文，
这一层代数严谨度是分水岭——18.703 给你直觉，18.701 给你证明能力。
