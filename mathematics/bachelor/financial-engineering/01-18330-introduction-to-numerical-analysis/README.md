# 18.330 · Introduction to Numerical Analysis 数值分析导论

> **课程主页**：[Spring 2012 · Prof. Laurent Demanet](https://ocw.mit.edu/courses/18-330-introduction-to-numerical-analysis-spring-2012/)
> **预估投入**：约 120 小时
> **先修**：18.03 + 18.06 + 编程

## 课程定位（为什么学它）

浮点运算、插值、数值微分积分、矩阵算法的稳定性。密码学工程实现（大数运算、模乘的侧信道安全）和量化交易系统（数值稳定性）共同的地基。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业（如适用）
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融科技的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 浮点误差的系统性分析：从 catastrophic cancellation 到算法重排
- 大整数乘法的复杂度阶梯：从学校乘法到 Karatsuba
