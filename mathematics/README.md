# Mathematics · 本硕博数学 + 计算机 + 密码学 + 金融工程课程作品集

> **目标**：以 MIT OpenCourseWare 免费课程为主线，系统修完**数学、计算机（Python / C / R / 算法）、密码学、金融工程**四个方向在本科、硕士、博士三个层级的课程，
> 以「笔记 + 习题解答 + 编程实现 + 心得 + 课程论文」的形式沉淀为可验证的数学与计算能力作品集，支撑密码学 / 金融工程博士申请。
>
> 所有课程链接均已核实至 OCW 官网当前可用学期页。共 30 门 · 约 3,860 小时。

## 四方向 × 三层级的关系

```
              数学核心              计算机                密码学方向             金融工程方向
本科    微积分/线代/概率/离散    Python→C→R→算法导论    代数 + 数论 + 计算理论    金融理论 + 数值分析
硕士    实分析 + 统计推断        算法设计与分析          椭圆曲线                 金融数学旗舰课群
博士    测度论概率 + 泛函分析    高级算法（组合优化）    可证明安全（6.875）       高级随机过程
```

- **数学核心**与**计算机**是两条公共地基：数学给证明，计算机给实现——密码学和金融工程都同时需要两者
- **密码学线**：6.0001 → 6.006 → 18.062J → 18.703 → 18.781 → 18.783 → 6.087（C，读密码库）→ 18.404J → 6.875
- **金融工程线**：6.0001 → 6.0002 → 15.071（R）→ 18.600 → 18.650 → 18.642 → 15.450 → 18.175 → 15.070J
- 博士层汇合点：测度论概率（18.175）服务两条线；6.854J 的组合优化同时是金融优化与格密码的数学工具

## 每门课的产出规范（五件套 · 给导师看什么）

```
<course-folder>/
├── notes/          # 每讲一份用自己的话重述的笔记 + 复现至少一个证明
├── problem-sets/   # 全部习题独立完成，附完整推导与订正
├── code/           # 编程实现（Python / C / R：RSA、大数运算、Monte Carlo、GARCH）
├── reflections.md  # 三个最难概念的攻克过程 + 与研究方向的联系
└── paper/          # 一篇 8–12 页 expository paper（3–5 份原始文献，LaTeX）
```

完成一门课时勾选该课 README 中的清单，证书/成绩单放入课程文件夹。
