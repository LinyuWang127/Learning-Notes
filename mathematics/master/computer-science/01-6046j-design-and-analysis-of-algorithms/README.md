# 6.046J · Design and Analysis of Algorithms （算法设计与分析）

> **课程主页**：[Spring 2015 · Prof. Erik Demaine / Prof. Srini Devadas / Prof. Nancy Lynch](https://ocw.mit.edu/courses/6-046j-design-and-analysis-of-algorithms-spring-2015/)
> **预估投入**：约 150 小时
> **先修**：6.006 + 18.062J；教材 CLRS《算法导论》

## 课程定位（为什么学它）

分治、随机化、动态规划、贪心、网络流、P/NP 复杂度——课程日程里甚至有两讲密码学（哈希函数、加密原语），是算法线正式的中继站。助教解题视频（problem-solving videos）全开放，习题含完整解答。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融工程的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 网络流在金融清算与二部图匹配中的应用
- P vs. NP 与密码学单向函数：复杂度理论的哲学联系
- 近似算法初步：顶点覆盖的定价法与舍入法
