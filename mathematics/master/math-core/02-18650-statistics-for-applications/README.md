# 18.650 · Statistics for Applications 应用统计

> **课程主页**：[Fall 2016 · Prof. Philippe Rigollet](https://ocw.mit.edu/courses/18-650-statistics-for-applications-fall-2016/)
> **预估投入**：约 120 小时
> **先修**：18.600

## 课程定位（为什么学它）

统计推断的数学化版本：充分统计量、Cramér-Rao 下界、假设检验、线性回归渐近理论、Minimax。金融科技博士（金融统计/计量方向）的看家课。
