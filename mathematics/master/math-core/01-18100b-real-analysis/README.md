# 18.100B · Real Analysis 实分析

> **课程主页**：[Spring 2025 · MIT Mathematics](https://ocw.mit.edu/courses/18-100b-real-analysis-spring-2025/)
> **预估投入**：约 150 小时
> **先修**：18.02 + 18.03

> **替代版**：较易替代版：18.100A Fall 2020 — https://ocw.mit.edu/courses/18-100a-real-analysis-fall-2020/

## 课程定位（为什么学它）

数学成熟度的分水岭。ε-δ 语言、紧性、完备性、一致收敛、极限交换。2025 春最新版，全套讲义 PDF + 习题免费。这是导师判断你'能不能读数学'的最直接证据。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业（如适用）
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融科技的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- 为什么实数完备性不可省略：没有上确界性质会崩塌的定理清单
- 一致收敛 vs 逐点收敛：函数项级数可否逐项求导
