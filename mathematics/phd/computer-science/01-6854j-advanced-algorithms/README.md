# 6.854J · Advanced Algorithms （高级算法）

> **课程主页**：[Fall 2008 · Prof. Michel Goemans](https://ocw.mit.edu/courses/6-854j-advanced-algorithms-fall-2008/)
> **预估投入**：约 150 小时
> **先修**：6.046J + 18.06 + 数学成熟度（大量正确性证明）

## 课程定位（为什么学它）

线性规划（单纯形 / 椭球 / 内点）、网络流、数据结构、近似算法（含 Goemans 本人开创的 SDP 0.878 近似）——MIT 理论计算机博士的资格级算法课。组合优化正是金融工程（组合优化、风险最小化）与密码学（格密码中的优化问题）的交汇处。

## 输出物清单（导师验收标准）

- [ ] `notes/` — 每讲一份笔记（Markdown 或 LaTeX），文件名 `lec-NN-主题.md`
- [ ] `problem-sets/` — 全部习题独立完成，附完整解答（不可只写答案）
- [ ] `code/` — 编程实现/作业
- [ ] `reflections.md` — 课程心得：最难的三个概念 + 如何攻克 + 与密码学/金融工程的联系
- [ ] `paper/` — 一篇 8–12 页课程论文（expository paper），方向建议见 `paper/outline.md`

## 建议论文方向

- SDP 松弛与 MAXCUT 的 0.878 近似：从证明到实现
- 椭球法与内点法在组合优化中的对比综述
- 网络流的高级算法：cancel-and-tighten 的正确性分析
